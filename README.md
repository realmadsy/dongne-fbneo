# 동네오락실 에뮬레이터

[FinalBurn Neo](https://github.com/finalburnneo/FBNeo)에 [GGPO](https://github.com/pond3r/ggpo) 롤백 넷코드를 붙인 포크입니다. 비영리 온라인 아케이드 대전 플랫폼 동네오락실에서 씁니다. 판매하지 않으며 ROM을 포함하지 않습니다.

- **라이선스:** FBNeo는 `fbneo/src/license.txt`, GGPO는 `ggpo/LICENSE`를 따릅니다.
- **원본에서 바꾼 것:** `UPSTREAM.md`
- **빌드:** `BUILD.md`
